# اعتبارسنجی: شواهد رسمی، نه انطباق شبیه‌سازی‌شده.

## تصمیم‌های مستقل.

پارسر نوع XML پشتیبانی‌شده را تشخیص می‌دهد. `BasicRules` بخشی از مقادیر لازم، تاریخ، قالب اعشار، جمع کل، ردیف و مالیات، نوع سند و checksum حساب IBAN را بررسی می‌کند. این کنترل جایگزین کامل EN 16931 یا XRechnung نیست. بررسی تجاری، تأمین‌کننده، مجوز و پذیرش حسابداری تصمیم‌های جدا هستند.

حالت STRICT به PASS واقعی ابزار رسمی نیاز دارد. نبود تنظیم، اشغال بودن پردازشگر، خطا، مهلت تمام‌شده یا نتیجهٔ نامعین، عملیات را مسدود می‌کند. DEMO فقط سناریوی ساختگی را با برچسب نبود تأیید رسمی و خروجی داخلی مجاز می‌کند. اجرای موفق ابزار با معتبر بودن صورتحساب یکسان نیست.

## موتور خارجی با نسخهٔ ثابت.

نسخهٔ هدف KoSIT **1.6.3** و تنظیم XRechnung **2026-08-31** است. منبع و دلیل امنیتی در راهنمای پژوهش آمده است. `KositWorker` از APIهای `Configuration`، `InputFactory`، `DefaultCheck` و `Result` در JVM فرزند استفاده می‌کند. فقط پردازش موفق همراه `ACCEPTABLE` نتیجهٔ PASS می‌دهد. SVRL برای نمایش خطاست و تصمیم اصلی را عوض نمی‌کند.

```cmd
python scripts\setup_kosit.py
set "RF_KOSIT_DIR=C:\Projects\rechnungflow\tools\kosit"
python scripts\validate_kosit.py --kosit tools\kosit --input examples\invoices\01-ubl-office.xml --expect PASS
```

نصب‌کننده فایل نسخهٔ مشخص رسمی را می‌گیرد، SHA-256 منتشرشده را بررسی می‌کند، ورودی ZIP ناامن را رد و هش همهٔ تنظیم‌ها را ثبت می‌کند. نبود هش منتشرشده به بررسی صریح اپراتور و گزینهٔ جداگانه نیاز دارد. نشانی فایل حدس زده نمی‌شود. نصب به معنی پذیرش صورتحساب نیست. PASS در فرمان نمونه، انتظار قابل آزمون است؛ نتیجهٔ رسمی کسب‌شده در این محیط نیست.

## شواهد و ارتقا.

هش فایل نصب‌شده، سقف حافظه، زمان و هم‌زمانی کنترل می‌شود و راز برنامه از محیط فرزند حذف می‌شود. گزارش رمزگذاری‌شده باقی می‌ماند. اعتبارسنجی جدید به تاریخچه اضافه می‌شود، نه جایگزین شواهد قبلی. بستهٔ شواهد گزارش‌های تاریخی موجود را دارد. هش ثابت‌شده امضای ناشر یا تضمین کامل زنجیرهٔ تأمین نیست.

این محیط امکان دریافت باینری واقعی KoSIT را نداشت. پذیرش رسمی واقعی و اجرای شبکه‌ای نصب‌کننده تأیید نشده‌اند. بدل‌های آزمون آشکارا برچسب دارند و موتور رسمی نیستند. پیش از تولید، مجموعهٔ رسمی معتبر و نامعتبر، حالت‌های مالیات، گرد کردن، ارز و مسیر Windows را بررسی و گزارش نسخه‌دار نگه دارید. ارتقا نیازمند پذیرش مجدد است. استخراج PDF ترکیبی ZUGFeRD، امضا، انتقال Peppol و همهٔ پروفایل‌ها در این نسخه نیستند.
