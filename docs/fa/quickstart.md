# شروع کار با RechnungFlow.

نسخهٔ 0.1.0 یک برنامهٔ قابل اجرای Java 21 برای ورود صورتحساب XML، بررسی مستقل و تحویل به حسابداری است. این نسخه برای ارزیابی مهندسی و پایلوت است؛ آرشیو حسابداری دارای گواهی یا سامانهٔ پرداخت نیست. اجرای نمایشی به سرویس خارجی نیاز ندارد.

## اجرا در Windows CMD.

JDK 21 یا جدیدتر و Python 3.10 یا جدیدتر را نصب کنید. فرمان‌های `java`، `javac`، `jar` و `python` باید در PATH باشند. در پوشهٔ اصلی پروژه اجرا کنید.

```cmd
java -version
javac -version
python --version
scripts\build.cmd
scripts\run-demo.cmd
```

برای اجرای فایل JAR آماده فقط Java لازم است.

```cmd
java -jar rechnungflow-0.1.0.jar --demo
```

نشانی `http://127.0.0.1:8090` را باز کنید. نخستین اجرا رمز اولیهٔ تصادفی را در ترمینال نشان می‌دهد. در فضای کاری `demo` حساب‌های آزمایشی `admin`، `intake`، `reviewer`، `approver`، `approver2`، `finance` و `auditor` وجود دارند. در ابتدا رمز نمایشی آن‌ها یکسان است. این شیوه برای کار واقعی مناسب نیست. اجرای مجدد، رمز حساب‌های ذخیره‌شده را بازنشانی نمی‌کند؛ رمز اولیه را امن نگه دارید.

از بالای صفحه زبان EN، DE یا فارسی را انتخاب کنید. رابط فارسی راست‌به‌چپ است؛ شناسه‌های فنی و IBAN چپ‌به‌راست می‌مانند. تاریخ‌ها حتی در رابط فارسی بر اساس تقویم میلادی هستند.

## نخستین سناریو.

صورتحساب `NW-2026-1001` را باز کنید. هش اصل سند و برچسب روشن اعتبارسنجی نمایشی را ببینید. با `reviewer` مرکز هزینه، حساب دفتر کل و یادداشت بررسی را ثبت کنید. با `approver` مستقلاً تأیید کنید. با `finance` درخواست خروجی بدهید؛ پردازشگر پس‌زمینه آن را در دفتر آزمایشی داخلی ثبت می‌کند. این عمل ثبت واقعی در حسابداری خارجی یا پرداخت نیست.

برای ورود جدید، شمارهٔ صورتحساب متفاوت استفاده کنید. تکرار فایل و تکرار هویت تجاری شناسایی می‌شود. نمونه‌ها شامل CII، سند بستانکار، جمع ناسازگار، تغییر حساب بانکی و XML ناامن هستند. همهٔ نمونه‌ها ساختگی‌اند و مجموعهٔ دارای تأیید رسمی محسوب نمی‌شوند.

## توقف و ادامه.

با Ctrl+C متوقف کنید و همان مسیر `--data` را دوباره به کار ببرید. `master.key` را حذف نکنید. دادهٔ نمایشی را به فضای کاری سخت‌گیرانه تبدیل نکنید. مسیر دادهٔ دیگر، نمونهٔ مستقل برنامه است. پیش از انتشار در شبکه، راهنمای استقرار و اعتبارسنجی را بخوانید.
