# Changelog.

## 0.1.0 — 2026-10-10.

### English.

Initial engineering preview: four Java modules, three-language interface, immutable XML intake, validation boundary/history, supplier controls, independent approvals, encrypted single-node persistence, outbox recovery, evidence export, test suites and deployment documentation. Actual official-validator and production qualification remain open.

### Deutsch.

Erste Engineering-Vorabversion: vier Java-Module, drei Sprachen, unveränderte XML-Originale, Validierungsgrenze und Verlauf, Lieferantenkontrollen, unabhängige Freigaben, verschlüsselte Einzelinstanz, Outbox-Klärung, Nachweise, Tests und Betriebsdokumentation. Echte offizielle und produktive Abnahme bleiben offen.

### فارسی.

نخستین پیش‌نمایش: چهار ماژول Java، سه زبان، اصل XML ثابت، مرز و تاریخچهٔ اعتبارسنجی، کنترل تأمین‌کننده، تأیید مستقل، ذخیرهٔ تک‌گرهی رمز‌شده، بازیابی صف، شواهد، آزمون و مستند استقرار. پذیرش رسمی واقعی و تأیید تولید هنوز باز هستند.
