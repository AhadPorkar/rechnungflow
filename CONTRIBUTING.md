# Contributing.

## English.

Run `scripts/test.cmd` or `python3 scripts/test.py` before submitting. Include a failing regression for bug fixes and a clear business scenario for features. Keep all three locale dictionaries and guides synchronized. Use only synthetic invoices. Do not upload customer information, credentials, binaries or runtime data. Describe verification boundaries, schema changes and rollback. No compatibility claim without acceptance evidence.

## Deutsch.

Vor Änderungen alle Tests ausführen. Fehlerkorrekturen benötigen Regressionen, Funktionen ein Geschäftsszenario. Drei Sprachen synchron halten. Nur künstliche Belege verwenden; keine Kundendaten, Geheimnisse oder Laufzeitdateien hochladen. Prüfgrenzen, Datenänderungen und Rückkehrweg dokumentieren. Kompatibilität nur mit Nachweisen behaupten.

## فارسی.

پیش از ارسال آزمون‌ها را اجرا کنید. اصلاح خطا به آزمون بازگشتی و قابلیت به سناریوی تجاری نیاز دارد. سه زبان را هماهنگ نگه دارید. فقط سند ساختگی استفاده کنید و دادهٔ مشتری، راز یا فایل اجرایی وارد نکنید. مرز بررسی، تغییر داده و بازگشت را شرح دهید. سازگاری بدون پذیرش ادعا نشود.
