# Security reporting.

## English.

This engineering preview has no support SLA or independent security certification. Enable GitHub private vulnerability reporting before publication and use that channel for sensitive findings. Do not put credentials, real invoices or exploit details affecting a deployed customer in a public issue. Include version, synthetic reproduction and impact. Never test systems without authorization. Operators must isolate the service and complete the commercial gates.

## Deutsch.

Diese Vorabversion hat kein Support-SLA und keine unabhängige Sicherheitszertifizierung. Vor Veröffentlichung private Schwachstellenmeldungen in GitHub aktivieren. Geheimnisse, echte Rechnungen und sensible Kundendetails nicht öffentlich melden. Version, künstliche Reproduktion und Auswirkung angeben. Nur autorisierte Systeme prüfen. Betreiber müssen den Dienst isolieren und Freigabekriterien erfüllen.

## فارسی.

این پیش‌نمایش SLA پشتیبانی یا گواهی امنیت مستقل ندارد. پیش از انتشار گزارش خصوصی آسیب‌پذیری GitHub را فعال کنید. راز، صورتحساب واقعی یا جزئیات حساس مشتری را عمومی نکنید. نسخه، بازتولید ساختگی و اثر را بنویسید. فقط سامانهٔ دارای مجوز را آزمون کنید. جداسازی سرویس و شروط تجاری بر عهدهٔ اپراتور است.
